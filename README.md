\# AI Voice Agent Evaluation



Python-based outbound AI voice agent built using LiveKit Agents.



\## Technologies

\- Python

\- LiveKit Agents

\- Deepgram (Speech-to-Text)

\- OpenAI (Language Model)

\- Cartesia (Text-to-Speech)

\- Silero VAD

\- Twilio (Outbound Calling)



\## Project Overview

This project evaluates an AI medical receptionist using an automated AI patient.



\## Test Scenarios

1\. Appointment booking

2\. Appointment rescheduling

3\. Appointment cancellation

4\. Prescription refill

5\. Insurance inquiry

6\. Office hours

7\. Interruption handling

8\. Ambiguous requests

9\. Corrections

10\. Multiple requests



\## Evidence

The recordings/ folder contains 10 MP3 recordings,

transcripts, and audio reports.

\## Setup

1\. Install Python 3.12.

2\. Create a virtual environment.

3\. Install dependencies using requirements.txt.

4\. Configure required environment variables in .env.

5\. Start the LiveKit agent.



\## Security

API credentials are stored in .env and excluded from Git.
